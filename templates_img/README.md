# templates_img — 图像模板库

`find_image` 工具在这里查找 `<模板名>.png` 并在屏幕上做多尺度模板匹配（阈值 0.80）。

## 如何积累模板

- **Agent 自举**：让 agent 用 `capture_template(left, top, width, height, name)`
  把屏幕上某个图标/按钮截存为模板，之后就能用 `find_image(name)` 找到它。
- **手动添加**：自己截一张只包含目标图标的小图（建议 ≤100×100 像素，PNG），
  放进本目录即可，文件名就是模板名。

## 注意

- 模板应**只框住目标本身**，带过多背景会显著降低匹配率。
- 深浅主题外观不同的图标需要各存一份（如 `chrome浅色`、`chrome深色`）。
- 本目录刻意不预置通用模板：模板和本机 DPI/主题强相关，
  错误的预置模板会造成误匹配（负优化），按需自举更可靠。
